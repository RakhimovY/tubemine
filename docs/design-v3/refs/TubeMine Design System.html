Semantic exceptions to the monochrome rule. Color appears outside the sentiment widget only for feedback.danger (destructive actions, error states) and feedback.warning (quota-near-cap, recoverable risk), standard signals where removing color weakens accessibility and pattern recognition. Everything else stays monochrome.

Floating feedback. Four types: success, error, warning (proposed amber), info. Left-edge accent + icon-chip carry the meaning so the toast still reads correctly without color (WCAG 1.4.1). Dismissible; auto-dismiss only for success/info.

09 · Responsive
