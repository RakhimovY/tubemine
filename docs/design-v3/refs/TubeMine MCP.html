01 What is TubeMine MCP

TubeMine MCP is a remote Model Context Protocol server that lets your AI assistant pull and analyze YouTube comments directly inside the chat. Base models cannot fetch YouTube comments on their own, so TubeMine fills that gap and hands the data back to your model to reason over.

The server exposes two tools:

get_youtube_comments(video_url, sort, max)

video_urla public YouTube URL or ID
sortrelevance or time
maxhow many comments to fetch
Returns
The raw comment thread: author, text, likes, replies, and timestamps.

analyze_youtube_comments(video_url)

video_urla public YouTube URL or ID
Returns
A structured summary: sentiment breakdown, top words, and emojis, ready for the model to explain.

02 Setup: Claude Code

The fastest path is OAuth. Open the Connect page and click Authorize next to Claude Code. You will be redirected back once access is granted, no key to paste.

Prefer the terminal? Run this once in your project. Replace YOUR_KEY with your API key from the Connect page.

terminal 
claude mcp add --transport http TubeMine https://tubemine.tech/api/mcp --header 'Authorization: Bearer YOUR_KEY'

03 Setup: ChatGPT Developer Mode

ChatGPT connects through Developer Mode connectors.

  1. Open Settings
  2. Go to Apps
  3. Open Advanced
  4. Turn on Developer mode

Add a new connector with this server URL, then choose OAuth when prompted for authentication.

server url 
https://tubemine.tech/api/mcp

04 Setup: Claude Desktop

Claude Desktop reads MCP servers from its config file. Open claude_desktop_config.json and add a TubeMine entry under mcpServers. Replace YOUR_KEY with your API key, then restart the app.

claude_desktop_config.json 
{
  "mcpServers": {
    "TubeMine": {
      "url": "https://tubemine.tech/api/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_KEY"
      }
    }
  }
}

Claude Desktop is key-based. It does not support OAuth.

05 Setup: Gemini CLI

Gemini CLI reads servers from settings.json. Add a TubeMine entry under mcpServers using httpUrl, then restart the CLI.

~/.gemini/settings.json 
{
  "mcpServers": {
    "TubeMine": {
      "httpUrl": "https://tubemine.tech/api/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_KEY"
      }
    }
  }
}

Gemini CLI is key-based. It does not support OAuth.

06 Authentication

There are two ways to authenticate, depending on what your client supports.

  • OAuthOne click on our site. Clients that support it (Claude Code, ChatGPT) redirect you to TubeMine, you approve, and you are connected. Nothing to copy.
  • API keyFor clients without OAuth (Claude Desktop, Gemini CLI), paste your key into the config as a Bearer token.

Get your key from the Connect page (or the MCP / AI Access tab in your dashboard). From there you can also rotate the key, which generates a new one and immediately revokes the old key on every connected client, and revoke any individual client without affecting the others.

Treat your key like a password. It grants access to your TubeMine quota. Never commit it to a public repository.

07 Usage and limits

MCP calls count toward the same monthly usage as the web app. A single analyze_youtube_comments call counts the comments it fetches, the same way an analysis in the dashboard does.

  • Free5,000 comments per month, generous for trying the tools and light use.
  • Pro100,000 comments per month for heavier, regular workflows.

There is no hard cap today. If you go over, we will not cut you off mid-task. We ask only that usage stays within fair-use bounds so the service stays fast for everyone. If your needs are unusual, reach out and we will sort out a plan that fits.

08 Troubleshooting

Most issues fall into one of these.

  • Key invalidMake sure you copied the full key and that it is sent as Authorization: Bearer YOUR_KEY. If you rotated recently, the old key is dead, paste the new one.
  • Client does not see the toolsConfirm the server URL is exactly https://tubemine.tech/api/mcp and that the entry sits under mcpServers.
  • Still nothing? Restart the clientClaude Desktop and Gemini CLI load MCP config at startup. Fully quit and reopen after editing the config.
  • Missing GET, POST, or DELETE handlersThis means the client reached an endpoint that is not the MCP route. Point it at /api/mcp exactly, with no trailing path, and use the HTTP transport.

Stuck after all that? Email hello@tubemine.app with your client and the error and we will help.
